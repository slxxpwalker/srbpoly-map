# แผนที่วิทยาลัยสารพัดช่างสระบุรี (ต้นแบบ)

- `index.html` คือหน้าแผนที่หลัก เปิดในเบราว์เซอร์ได้เลย หรืออัปขึ้น GitHub Pages เพื่อใช้ GPS จริง (ต้องเป็น HTTPS)
- `concept/campus-warp-demo.html` คือเดโม่แนวคิดแรก ใช้แผนที่สมมติ

## แก้ข้อมูลอาคาร
เปิด `index.html` แล้วหา `const BUILDINGS=[` ด้านบนของสคริปต์
- `name` ชื่ออาคาร
- `units` รายชื่อหน่วยงาน/แผนก เช่น `['งานทะเบียน','แผนกช่างยนต์']` (ค้นหาได้ทันที)
- `px` ขอบอาคาร เป็นพิกัดพิกเซลบนภาพ Google Maps (zoom 19.5, 0.2044 ม./px)
- `rs.floors` ห้องของแต่ละชั้น (ตอนนี้มีเฉพาะอาคาร 7 และ 11 และเป็นข้อมูลตัวอย่าง)
- `RED_ROOF` หมายเลขอาคารที่หลังคาเป็นสีแดง

## ลิงก์ QR ประจำอาคาร
ต่อท้ายที่อยู่เว็บด้วย `#b<หมายเลข>` เช่น `https://<user>.github.io/saraburi-campus-map/#b11`

## เวอร์ชัน 3 มิติ (12 พ.ย. 2569)
`index.html` เป็นแบบจำลอง 3 มิติแล้ว (เวอร์ชัน 2 มิติเดิมอยู่ในประวัติ git)
- `BUILDINGS`: `name` ชื่อจริง (เว้น '' ถ้ายังไม่ทราบ), `hint` ชื่อชั่วคราว, `sty` หน้าตาอาคาร (red/blue/new/pink/hall/brick/shed), `nF` จำนวนชั้น, `units` หน่วยงาน, `rs.floors` ห้องแต่ละชั้น
- `POIS`: จุดสำคัญที่ไม่ใช่อาคาร (ประตู ลานโดม เสาธง ฯลฯ)
- โฟลเดอร์ `photo/` เป็นรูปอ้างอิง มีป้ายทะเบียนรถและบุคคลติดอยู่ ไม่ควร push ขึ้น repo สาธารณะ
